# :cd: Installing NitroWin on an Existing System

1. Install the some sort of [.NET 10 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Any edition should work fine.

2. Install [NitroWin](https://github.com/nitrowinproject/NitroWin/releases/latest). Use the file whose name starts with `NitroWinSetup`. Make sure to use the appropriate one for your CPU architecture.

3. Configure NitroWin.
   - Your NitroWin folder will be located under `%ProgramData%\NitroWin`. If it doesn't exist run `nitrowin update` from an elevated terminal prompt.

   - Use [this guide](configuration.md) for further information.
