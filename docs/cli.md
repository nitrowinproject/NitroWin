# :computer: NitroWin CLI

From release 3.2.0 and onwards, NitroWin will ship as a CLI.

## :wrench: Command Line Arguments

By running NitroWin with `--help` you will get a list of all available command line arguments:

```text
USAGE:
    nitrowin [OPTIONS] <COMMAND>

OPTIONS:
    -h, --help       Prints help information
    -v, --version    Prints version information

COMMANDS:
    apply     Applies all locally cached tweaks
    apps      Installs all apps from the Apps.yml file
    update    Updates locally cached tweaks
```
